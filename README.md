# resume

made using [rendercv/rendercv](https://github.com/rendercv/rendercv)

- `resume.yaml`: the general resume, published at <https://guneet.dev/resume>.
- `targeted/<target>.yaml`: targeted resumes, published at `https://guneet.dev/resume/<target>`.

Run `make setup` once, then `make build` to render every resume to `rendercv_output/`.
